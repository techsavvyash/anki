# @anki/constants

Shared constants for the Anki monorepo.

## Usage

```typescript
import { API_CONFIG, SM2_CONSTANTS, CARD_STATES } from '@anki/constants';
```

## Constants

- **API_CONFIG**: API configuration including base URL, timeout, and default headers
- **SM2_CONSTANTS**: Spaced repetition algorithm constants (SM-2)
- **CARD_STATES**: Card state constants
- **UPLOAD_LIMITS**: File upload limitations
- **SUBJECT_COLORS**: Color palette for subject categorization
